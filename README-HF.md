# AI Lip Sync Demo 🎬

This Space demonstrates AI-powered lip synchronization using the Wav2Lip model. Upload a video/image and audio, and watch as the AI makes the face speak!

## Features 🌟

- High-quality full-face animation
- Support for images and videos
- Live microphone recording
- Built-in sample avatars
- Video trimming and post-processing
- GPU-accelerated processing

## How to Use 🚀

1. Choose an avatar or upload your own image/video
2. Record audio or upload a WAV/MP3 file
3. Click "Start Animation" and wait for processing
4. Download or trim the resulting video

## Tips for Best Results 💡

- Use clear, well-lit frontal face images/videos
- Ensure good audio quality with clear speech
- For videos, use stable footage with minimal movement
- Recommended video resolution: 480p or higher

## Technical Details 🔧

- Based on Wav2Lip GAN model
- GPU-accelerated processing
- Supports various input formats
- Processing time: ~30 mins for 30-second video
